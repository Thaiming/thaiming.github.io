# 🥗 뾰로롱 쇼츠 편집기

유튜브 건강 쇼츠 채널 **뾰로롱** 전용 웹 영상 편집기. 브라우저에서 바로 열어 쓰고, 결과물(MP4/WebM·PNG)은 기기로 내려받습니다.

- **주소**: https://thaiming.github.io/ppyororong-editor/
- **규격**: 1080×1920 (9:16) · 30fps
- **설치 불필요**: 크롬/엣지(PC), 사파리(iPhone) 모두 동작. 데이터는 서버로 보내지 않고 브라우저 안에서만 처리됩니다.

## 기능

| 구분 | 내용 |
| --- | --- |
| 캔버스 미리보기 | 실제 1080×1920 캔버스를 축소 표시. 유튜브 하단 UI 안전지대(y 1210–1440) 가이드 ON/OFF |
| 컷 유형 | **첫 화면**(상단 스크림 + 대형 타이틀 104px), **본문**(하단 안전지대 자막 92px), **엔딩**(중앙 문구, ♥만 빨강) |
| 자막 | Noto Sans KR 700/900, 검은 외곽선. 1줄 흰색 / 2줄부터 노랑(#FFD600) 또는 흰색 선택 |
| 컷 편집 | 추가 · 복제 · 순서 이동(▲▼) · 삭제 · 컷 길이(초) |
| 이미지 | 업로드 시 1080×1920 중앙 크롭, 확대(100–250%)·좌우/상하 미세 조정. 여러 장 한 번에 넣기 지원 |
| 나레이션 | MP3/WAV/M4A 업로드 → 전체 타임라인 재생/일시정지 미리보기, 볼륨 조절 |
| 저장 | 브라우저 자동 저장(localStorage + IndexedDB), 프로젝트 JSON 내보내기/불러오기 |
| 내보내기 | 1080×1920 30fps 영상(MediaRecorder: MP4 우선, 미지원 시 WebM) + 오디오 합성, 진행률 표시. 컷별 PNG 저장 |
| 폰트 | Noto Sans KR 400/700/900 woff2를 저장소에 직접 넣어 씀(`fonts/`) — 오프라인·저속 환경에서도 같은 글씨 |

## 사용 순서

1. 첫 화면 컷에 제목을 넣고 이미지를 올립니다.
2. **＋ 본문**으로 컷을 늘리고, 이미지를 여러 장 한 번에 선택해 채웁니다.
3. 각 컷 자막을 입력하고 길이(초)를 조정합니다(예: 22컷 × 2~2.3초 + 엔딩 2.5초).
4. 나레이션 파일을 올리고 ▶재생으로 전체를 확인합니다.
5. **영상 저장** → 실제 길이만큼 녹화된 MP4/WebM 파일이 다운로드됩니다. 유튜브 스튜디오에 업로드하세요.

## 파일 구성

- `index.html` — 화면
- `styles.css` — 스타일
- `app.js` — 캔버스 렌더링·재생·녹화·저장 로직
- `fonts/` — Noto Sans KR 400/700/900 woff2 (SIL Open Font License, `fonts/OFL.txt`)

## 수정할 때

- 파일을 고친 뒤에는 `index.html` 끝부분의 `styles.css?v=N`, `app.js?v=N` 숫자를 하나 올려 주세요. 페이지 캐시(10분) 때문에 휴대폰에서 예전 화면이 보일 수 있습니다.
- 영상 형식은 화면에서 **자동 / MP4 / WebM** 중 고를 수 있습니다. 기본은 MP4(H.264)입니다.

## 참고

- 영상 녹화는 실시간입니다. 60초 영상은 약 60초 걸리며, 그동안 탭을 닫거나 다른 앱으로 전환하지 마세요.
- 브라우저 자동 저장은 기기별로 따로 됩니다. 다른 기기에서 이어서 하려면 **프로젝트 저장(.json)** 파일을 옮겨 **불러오기** 하세요.
- iPhone은 iOS 16.4 이상 사파리에서 영상 저장이 동작합니다.
