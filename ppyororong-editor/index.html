뾰로롱 쇼츠 편집기 사용법

  1. 컷 구성 — 22컷 기준으로 ＋ 본문을 눌러 늘리세요. 컷마다 ▲▼로 순서를 바꾸고, 복제·삭제할 수 있습니다.
  2. 이미지 — 컷을 고른 뒤 이미지 선택에서 여러 장을 한꺼번에 고르면 현재 컷부터 차례로 들어갑니다. 확대·좌우/상하 슬라이더로 구도를 미세 조정합니다.
  3. 자막 — 줄바꿈으로 줄을 나눕니다. 첫 줄은 흰색, 둘째 줄부터는 노랑(#FFD600) 또는 흰색을 고를 수 있습니다. 모든 글자에 검은 외곽선이 들어갑니다.
  4. 엔딩 — 엔딩 컷에서 엔딩 문구 넣기를 누르면 “구독 누르시고 / 오늘도 건강하세요 ♥”가 들어가고 ♥만 빨갛게 표시됩니다.
  5. 나레이션 — MP3/WAV/M4A를 올리고 ▶재생으로 전체 타임라인을 확인합니다. 컷 길이의 합과 나레이션 길이가 비슷해야 어긋나지 않습니다.
  6. 영상 저장 — 영상 저장을 누르면 1080×1920·30fps로 실시간 녹화합니다(영상 길이만큼 소요). 크롬·엣지는 MP4를 지원하면 MP4, 아니면 WebM으로 저장됩니다. 아이폰 사파리는 iOS 16.4 이상에서 동작합니다. 컷 하나만 이미지로 받을 때는 현재 컷 PNG, 전체 컷은 전체 컷 PNG (ZIP)을 누르세요.
  7. 유튜브 업로드 — 저장한 파일을 유튜브 스튜디오에 올리고, 아동용 아님 · 변경된 콘텐츠(AI) 예로 설정하면 됩니다.
